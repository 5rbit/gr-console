# GR2 측정 시험 절차 (PLC V1.4.2)

현장에서 네 가지를 확인한다: **A 레이저 측정**, **B Z 오프셋 자동 교정**, **C 토크 내경 측정**, **D 그리퍼 파지 판정**.
모든 시험은 gr-console **측정 모니터 → 기록·분석** 탭으로 기록하고 같은 화면에서 분석한다.
합격 기준 중 "제안" 표시는 첫 시험 결과를 보고 조정할 값이다.

### 0.2 gr-console

- 콘솔 PC 가 GR2(192.168.1.102) 에 닿는 서브넷에 있어야 한다.
- 사이드바 GR2 레이아웃 검증에서 `WEBMON` (LayoutSig `16#6306_CEEE`) 과 `LASERDIAG` (`16#2917_602B`) 가 통과해야 한다.
  불일치면 PLC 다운로드가 반영되지 않은 것이다 — 기록·레이저 탭이 503 을 돌려준다.
- `측정 모니터 → 축 / 센서` 에서 그리퍼 상태 비트(토크 검출·토크 멈춤·G 멈춤)가 움직이는지 먼저 본다.

## 1. 기록 도구

1. **측정 모니터 → 기록·분석** 탭에서 이름·시험·메모·주기(기본 50 ms)를 넣고 **기록 시작**.
2. 시험 동작 중 단계마다 **표시** (직접 입력 또는 `측정 시작`·`타이어 돌림`·`다른 타이어`·`파라미터 변경`·`이상 동작`).
3. **기록 정지** → 분석이 바로 열린다. 목록에서 **분석**·**CSV**·**삭제**.

- 기록은 백엔드가 하므로 브라우저를 닫아도 이어진다. 30 분이 지나면 스스로 멈춘다.
- 저장 위치 : 콘솔 `data/records/<id>/` — `meta.json` (시험 정보, 시작·끝 스냅샷), `samples.jsonl` (한 줄 = 한 샘플 또는 표시).
- 시작·끝 스냅샷 : PARA 레이저·토크 파라미터, LASERDIAG (센서 상태·교정), MEASLOG 누적 수. 끝 스냅샷에는 **기록 중 새로 생긴 LASERDIAG 진단 이력**과 **MEASLOG 종류별 마지막 기록**이 들어간다.
- 샘플 항목 (WEBMON) : Mode, 현재 작업(규격·셀·목표), 진행 스텝, 알람 코드, X/Y/Z/G 축 (위치·목표·속도·토크), 그리퍼 (아이템 감지, GID L/F/R/B 거리, FLD, 상태 비트, 멈춤 시간), 측정 진행 (Item, LastBead), MeasLog 수.
- 20 ms 는 S7 부하가 커서 필요한 짧은 구간에만 쓴다.

## A. 레이저 측정 — 비드 인식 변경 확인

**목적** : 규격 내경이 부정확해도 실제 비드를 인식하는지 (최소 거리 + 비드 여유, 중간값 게이트), 내경·편심·상단 비드 높이·타이어 높이·PICK 마지막 비드가 안정적인지.

**준비** : 규격이 맞는 타이어 1 종. 가능하면 규격 내경이 실제와 20 mm 이상 다른 코드로 등록된 타이어 1 종.

**절차**

1. 기록 시작 — 시험 `레이저 측정`, 주기 50 ms, 메모에 타이어 코드·셀.
2. MEASURE (TaskType 16#44, MeasureItem 켬) 작업 3 회. 회차 사이에 `타이어 돌림` 표시.
3. 같은 타이어 PICK 3 회.
4. 규격 내경이 다른 타이어로 2–3 을 반복 (`다른 타이어` 표시).
5. 기록 정지.

**확인**

- 구간 `들어갈 때 측정` / `나갈 때 측정` : 프로파일에서 비드 점 무리가 규격 내경선에서 떨어져 있어도 재현 표의 비드 높이가 위쪽 비드 띠에 있다. 내부 공간(중간선 오른쪽 점)은 비드로 잡히지 않는다.
- PLC 진단 이력 : 원 맞춤 OK, 플래그 없음, 편차 폭 < p404.
- MEASLOG Item : 상태 Done, 들어갈 때·나갈 때 내경 차 ≤ 3 mm (제안), 같은 타이어 3 회 내경 편차 ≤ 2 mm (제안).
- 재현 경계 높이와 PLC 경계 높이 차 ≤ Z 속도 × 주기 + 2 mm (제안).
- 구간 `PICK 하강 비드 측정` : 마지막 비드 − 목표가 타이어마다 일정하고, `FUNC.MeasureLastBeadPos.PickZTarget` 이 래치되면 Z 목표 그래프가 그만큼 바뀐다 (마지막 비드 − 20 이 작업 Z 보다 높고 타이어 높이 × 0.3 이내일 때만).

**문제일 때** : 방향 하나만 비드를 못 보면 (재현 본 샘플 0, 플래그 무응답) 렌즈·케이블 확인. 비드가 내부 공간으로 잡히면 비드 여유를 5 로 줄여 재현해 보고 결과를 기록에 남긴다.

## B. Z 오프셋 자동 교정

**목적** : 센서끼리의 설치 높이 차를 PARA GIDx_ZOffset 에 반영해 방향별 비드 높이 편차를 줄인다. 오프셋 평균은 그대로 둔다 (상대 높이만 맞춤).

**절차**

1. 기록 시작 — 시험 `Z 오프셋 교정`.
2. **레이저 센서** 탭 → 교정 시작 (또는 감시 테이블 `"LASERDIAG".ZCal.Enable` = TRUE). 필요하면 먼저 `상태·이력 초기화`.
3. MEASURE 작업(MeasureItem) 또는 HMI 수동 측정을 p425 회 (기본 5). **매회 타이어를 90° 돌린다** — PCR 3 방향은 돌리지 않으면 기울기와 설치 오차를 구분할 수 없다. 들어갈 때·나갈 때 각각 1 회로 센다. PICK 하강은 세지 않는다.
4. 레이저 센서 탭 교정 상태가 `완료` 또는 `실패` 가 되면 기록 정지.
5. 검증 : 새 기록으로 MEASURE 3 회.

**확인**

- 분석 `Z 오프셋 교정` 카드 : 상태 완료, 방향별 표준편차 ≤ p426, `PARA.Sensor` 표에서 GIDx_ZOffset 이 바뀜 (합은 거의 그대로), CSV 저장 요청됨 (`MACHINE.CSV.Para.Export`).
- 검증 기록의 PLC 진단 이력 : 방향별 비드 편차 |값| ≤ 1 mm (제안), 편차 폭이 교정 전보다 작다.
- 실패 코드 : 1 취소 (도중에 끔), 2 표준편차 초과, 3 보정량 초과 → 알람 4213, PARA 변경 없음. 방향이 빠진 측정은 건너뜀 수로 센다.

## C. 토크 내경 측정

**흐름 (PL_MeasureItem)** : 10 아이템 감지·중심 출처 (들어갈 때 원 맞춤이 유효하면 그 편심, 아니면 스냅샷) → 100 XY 를 중심으로 이동 → 200 G 토크 제한 적용 후 최대로 벌림 → 300 토크 도달 위치 저장 → 400 최소로 돌아가 반복 → 900 평균 + p953 보정 = Torq_InnerDia (수동 측정은 회당 G 위치 + p954).
토크 제한은 p952 (0 이면 p941), 토크 검출은 p949/p950/p951. 정합 : 레이저·토크 모두 유효하고 차가 허용 편차 이내면 평균(Done), 넘으면 토크 값(Mismatch).

**절차**

1. 기록 시작 — 시험 `토크 내경 측정`, 주기 20–50 ms.
2. p952 = 0 (기존 동작) 으로 MEASURE 3 회.
3. p952 를 바꿔 (예 : 20 %, 30 %) 각 3 회. 바꿀 때마다 `파라미터 변경` 표시와 메모.
4. 기록 정지. 파라미터별로 기록을 나눠도 된다.

**확인**

- G 축·토크 그래프 : 벌림 중 토크가 제한값 근처에서 평탄해지고, 그리퍼 상태 변화에서 토크 검출 켜짐이 G 가 멈춘 뒤에 온다 (가속 중 켜짐 없음).
- MEASLOG Item 값 : 토크 1회 G / 2회 G 차 ≤ 2 mm (제안), |토크 − 레이저 내경| ≤ 허용 편차 (상태 Done, Mismatch 아님).
- p952 에 따른 토크 내경 변화가 타이어 변형 방향(토크가 클수록 커짐)과 맞고 크기가 작다.
- 보정값 정하기 : 토크 설정별로 (레이저 내경 − 토크 1·2회 G 평균) 이 일정하면 그 값을 p953 에 넣는다. 레이저 내경 자체가 실측(게이지)과 다르면 p428 로 맞춘다.
- 알람 3211 이 나면 그 시점의 아이템 감지와 G 위치를 기록에서 본다.

## D. 그리퍼 파지 판정

**판정 (GripperJudge)** : 토크 멈춤이 목표에서 p942 이내면 **토크 파지** (정상). 허용 범위 밖에서 멈추면 **Short** → 4025 (G 그리퍼 타임아웃). PICK 에서 아이템을 못 느끼면 6016. 토크 없이 멈춤(StallNoTorque)은 힘을 안 쓰는데 안 움직이는 상태 — 기구 걸림을 의심한다.

**절차**

1. 기록 시작 — 시험 `그리퍼 파지 판정`, 주기 50 ms.
2. 규격이 맞는 타이어 PICK 5 회.
3. (선택, 현장 안전 확인 후) 경계 조건 : 규격 내경이 실제보다 큰 코드로 PICK 1 회 → 범위 밖 멈춤·4025 가 나는지.
4. 기록 정지.

**확인**

- G 멈춤 구간 : 정상 PICK 은 모두 `토크 파지 · 아이템 감지`, 알람 없음.
- 토크 없이 멈춤 구간이 없다.
- 그리퍼 상태 변화 : 토크 멈춤 켜짐 → 아이템 감지 순서, 멈춤 시간이 타임아웃보다 충분히 짧다.
- 경계 조건 기록에서는 범위 밖 멈춤과 4025 가 같은 구간에 나온다.

## 결과 정리
